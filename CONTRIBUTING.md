# Contributing

Single-maintainer repository. Changes land via pull request only, with signed commits (enforced by the repository rulesets).

- Treat every change as **fleet-wide**: the default files here apply to every `cad0p` repository that lacks its own, and the workflows are pinned by consumers.
- Consuming repositories bump their pinned workflow SHA **manually** after review.
- Nothing secret goes in this repository — it is public.
